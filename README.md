# H+ — Aprende la H en español

Aplicación web educativa creada con HTML, CSS y JavaScript puro.

## Contenido
- Navegación por secciones.
- Reglas prácticas sobre el uso de la H.
- Flashcards interactivas con ejemplos.
- Ejercicio de completar palabras.
- Contador de aciertos.
- Dark mode.
- Diseño responsive para móvil y escritorio.
- Ilustración abstracta sencilla hecha con CSS, sin imágenes externas.

## Uso
Abre `index.html` en cualquier navegador moderno. No requiere servidor ni instalación.

## Archivos
- `index.html`: estructura.
- `styles.css`: diseño visual y responsive.
- `script.js`: lógica de flashcards, práctica y tema.
